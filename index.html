Software Engineer

JPMorgan Chase · Columbus, OH

  • Build and run a platform of 21 Spring Boot microservices on AWS ECS, backed by Aurora PostgreSQL.
  • Work on multi-region resilience across us-east-1 and us-east-2, including disaster-recovery design.
  • Develop Kafka event flows with Avro schemas and Schema Registry, plus Redis/ElastiCache caching.
  • Built a data publication pipeline: services publish events to Kafka, a Flink streaming job writes them into an S3/Glue data lake, and an hourly sync loads them into Snowflake, where a matching read-only view serves downstream consumers.
  • Ship infrastructure as code with Terraform and deliver through Jenkins and Spinnaker pipelines.
